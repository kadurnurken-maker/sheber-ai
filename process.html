What the Alpha Was

The Alpha stage focused on core mechanics. I started with skeletal tracking on a school computer to verify if MediaPipe could accurately detect joint angles during wrestling moves. At this stage, there was no real interface—just a raw camera feed with landmark overlays and a basic guide image for reference.

What Was Missing

ProblemNo web interface — ran as a local Python script only
ProblemBasic skeleton tracking but no automated rep counting logic
ProblemStatic guide images didn't provide dynamic feedback
ProblemNo ranking or progression system for the athlete

Key Feedback Received

Sponsor / Coach«The skeletal tracking is precise, but it needs a real UI to be useful in a gym.»
→ Target: Web UI
User Testing«I can see the points on my body, but I don't know if I'm doing it right.»
→ Led to HUD metrics

Transition to Beta

In Beta, I moved the project to a full Streamlit web app. I experimented with a 'Neon AI PRO' visual style. The biggest technical challenge was the WebRTC connection error (shown above), which required deep-diving into STUN/TURN server settings to ensure a stable video stream on different networks.

Technical Challenges Solved in Beta

ChallengeWebRTC connection lag and initialization errors on cloud hosting
FixImplemented custom STUN servers and optimized frame processing threads
Challenge'Neon' UI was visually loud and distracted from the training feed
FixDecision to simplify the palette for the final production version

The Final Polish

The final version represents a shift from 'AI PRO' (experimental neon) to a cleaner, more stable SHEBER brand. I simplified the UI to a premium gold-on-dark palette, optimized the MediaPipe complexity for mobile performance, and synchronized the XP/Rank system to prevent lag. The GitHub repository (shown above) contains the finalized production code.

Final Metrics

DesignProfessional minimalism. High contrast for gym visibility.
StabilityResolved all WebRTC handshake issues. Smooth 30FPS tracking.
LogicFull bilateral tracking (both knees) for stance independence.
