What the Alpha Was

The Alpha ran entirely in a terminal window. It used MediaPipe to detect body landmarks and calculate the left knee angle — but only the left side. There was no interface, no camera stream over the web, no rep counter the user could see, and no design whatsoever. It was a command-line proof that the maths worked.

What Was Missing

ProblemOnly terminal — coaches and athletes couldn't use it without Python knowledge
ProblemZero rep counting — no feedback at all
ProblemOnly left knee tracked — crashed when left side was hidden
ProblemNo rank, no XP, no motivation system

Key Feedback Received

Sponsor / Coach«It only works in terminal, not usable for real training»
→ Led to Web UI
User Testing«Throws are not being counted, there's no feedback»
→ Led to rep counter + HUD
User Testing«Can't tell my rank or progress»
→ Led to XP & rank system

Technical Challenges Solved in Beta

ChallengeStreamlit session_state not thread-safe → caused missed/doubled reps
Fixthreading.Lock() guards global counters; UI syncs on each render
ChallengeMediaPipe model re-initialized every frame → severe lag
Fix@st.cache_resource loads model once at startup, reused across sessions
ChallengeOnly left knee tracked → crash when occluded
FixBoth knees analyzed; min(left, right) angle used; try/except wrapping
ChallengeMissing shalu.jpg crashed app
Fixos.path.exists() check with fallback to hero.jpg

What Still Needed Work After Beta

The neon «SHEBER AI PRO» design was visually loud but cluttered. WebRTC caused lag on cloud. Rank names weren't visible enough. Progress bar briefly showed 100% at level-up before resetting. HUD text clipped on small screens.

Phase 03
Final
May 2025
Production Release · v2.0

What Changed in the Final Version

The final version is a refined, stripped-back release that addresses every issue flagged in Beta testing. The neon «AI PRO» branding was removed in favour of a clean, confident identity: just SHEBER. The focus shifted from visual maximalism to performance and reliability.

Three Core Improvements

UI SimplifiedDropped neon overdesign. Clean gold-on-dark palette, larger rank display, readable HUD on all screen sizes.
Lag Eliminatedmodel_complexity lowered from 1 → 0. Frame skip logic added (process every 2nd frame when CPU > 80%). Target: <30ms per frame.
XP Sync FixedProgress bar clamped to rank_max before promotion — no more 100% flash bug. Rank boundary calculation corrected.
Bilateral StabilityBoth knees independently wrapped in try/except. min() angle logic prevents false negatives for any stance orientation.
