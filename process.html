What the Alpha Was

The Alpha focused on core mechanics. I tested skeletal landmark tracking to verify whether MediaPipe could detect joint angles during wrestling moves. At this stage there was no web interface — just a raw camera feed with landmark overlays and a static technique guide image for reference.

What Was Missing

ProblemRan as a local Python script only — no web interface or URL to share
ProblemNo automated rep counting — zero real-time feedback for athletes
ProblemOnly left knee analyzed — crash when that side was occluded
ProblemNo XP, no rank system — nothing to motivate continued training

Transition to Beta

Beta moved everything to a full Streamlit web app with WebRTC live camera streaming. I experimented with a bold «SHEBER AI PRO» neon aesthetic. The biggest technical hurdle was a WebRTC connection error (screenshot above) that required configuring custom STUN servers and introducing threading.Lock() to prevent race conditions in rep counting.

Technical Challenges Solved

Challengesession_state not thread-safe → missed and doubled reps
Fixthreading.Lock() guards global counters; UI syncs on each render cycle
ChallengeMediaPipe model re-initialized every frame → severe lag
Fix@st.cache_resource loads model once at startup, reused across sessions
ChallengeLeft knee only → crash when that side was occluded
FixBoth knees wrapped in try/except; min(left, right) angle used
ChallengeMissing image file crashed the entire app
Fixos.path.exists() check added; fallback to hero.jpg

What Still Needed Work After Beta

The neon design was visually overloaded and distracted from the camera feed. WebRTC caused lag on cloud hosting. The rank name was barely noticeable. The XP progress bar briefly flashed 100% on level-up before resetting. HUD text clipped on small screens.

The Final Polish

The final version is a focused, stable release. The «AI PRO» neon branding was replaced with a clean SHEBER identity — gold on dark, high-contrast, readable under gym lighting. Performance was the top priority: model complexity reduced from 1 → 0, frame skipping added, and the XP synchronisation bug fixed at its root.

Three Core Improvements

UI SimplifiedNeon dropped. Gold-on-dark palette. Rank name prominent in header. HUD readable at all screen sizes.
Lag Eliminatedmodel_complexity: 1 → 0. Every 2nd frame skipped when CPU > 80%. Target: <30ms per frame.
XP Sync FixedProgress bar clamped to rank_max before promotion. No more 100% flash bug at level-up.
Bilateral StabilityBoth knees tracked independently. min() angle logic prevents false negatives for any stance.
